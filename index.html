Accepted Paper

1. Mobile-ConvViT: Parameter-Efficient Hybrid CNN-Vision Transformer for Low-Latency Edge Vision

Authors: Muhammad Abubakar, Sultan Mohyuddin, Fatah Chandio, Adeel Abro
Conference: 2026 IEEE 4th International Conference on Computer, Vision and Intelligent Technology (ICCVIT 2026) Submission ID: IEEE_ICCVIT-2026-000092

Abstract: Running Vision Transformers on low-power edge hardware is difficult because self-attention requires heavy computation and memory, while standard CNNs are fast but miss global context. This paper presents Mobile-ConvViT, a lightweight hybrid model that uses early 2D convolutional layers to shrink the image into a compact 8x8 feature grid, then applies multi-head self-attention over only 64 tokens to capture global context. On an NVIDIA T4 GPU, the model reaches 78.4% Top-1 accuracy on CIFAR-10 with 1.28M parameters and 1.48 ms latency (~675 FPS), outperforming ResNet-18 and MobileNetV3-Small in speed and efficiency.

2. Lite-TemporalViT: Decoupled Spatial-Temporal Transformer for Ultra-Low Latency Aerial Drone Surveillance

Authors: Sultan Mohyuddin, Muhammad Abubakar, Kamran Ali Memon, Mudassar Ali, Muhammad Asghar Khan
Conference: ICCT 2026 Paper ID: 1776

Abstract: Real-time video analysis on small drones is limited by onboard compute and memory. Standard 3D CNNs and video transformers process spatial and temporal information together at high computational cost. This paper presents Lite-TemporalViT, a factorized hybrid architecture that decouples spatial and temporal extraction using a lightweight 2D CNN with a 2-layer temporal transformer encoder. Evaluated on an NVIDIA T4 GPU using 4-frame clips, it reaches 79.2% Top-1 accuracy with 1.28M parameters and 1.58 ms latency (~632 FPS), outperforming 3D-ResNet18, SlowFast-Lite, and ViViT-Tiny.
